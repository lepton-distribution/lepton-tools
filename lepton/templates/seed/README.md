# Graine {{name}}

Graine (seed scion) du projet Lepton `{{name}}`, créée par `lepton seed new`.

- `scion/.scion/lepton-graine.json` : manifeste du projet (noyau, BSP, applications,
  bibliothèques, backend, configurations, XML mklepton).
- `scion/.scion/.scion.sources.list`, `.scion.ramifications` : origine des greffons, gérées par
  scion ; à modifier par `lepton seed add / remove / replace`.

État : `lepton seed status`.
